# NIRS｜非侵襲性呼吸支持臨床決策導航

繁體中文成人急性呼吸支持評估與教學網頁。

## 使用流程
1. **先排除危急情況**：六項氣道、呼吸、循環警訊，全部確認為無才解鎖後續評估。
2. 輸入病因、呼吸作功、支持方式、生命徵象與動脈血氣。
3. 依病況評估一般氧療、HFNC、CPAP 或雙水平 NIV。
4. 複評臨床變化、血氣與限定族群及時間的 ROX；惡化時停止常規推薦。

## 教學病例
- COPD 高碳酸性酸中毒：辨認雙水平 NIV 的適應情境與早期療效。
- 肺炎低血氧：HFNC 評估及 2 小時 ROX 不確定區間。
- 心因性肺水腫：CPAP／雙水平 NIV 選擇。
- 休克與意識惡化：先啟動氣道急救，不進入常規模式選擇。
- 代謝性酸中毒：避免只憑低 pH 推薦 BiPAP。

病例均為虛構。所有輸入僅在瀏覽器頁面記憶體處理，無後端、無追蹤、無病人姓名或病歷號欄位。重新整理即清除。

## 限制
供醫療專業人員輔助與教學，尚未經前瞻性臨床驗證，不代替床邊判斷或自動開立呼吸器處方。依院內流程及個別醫囑使用。NIV 壓力與 HFNC 流量需由醫療團隊滴定。

參考 ERS/ATS 2017、ERS HFNC 2022、ATS NIRS 2026、BTS oxygen 2017 與 Roca ROX 2019。原始連結於網頁列出。資料查核日期：2026-10-19。

## 開發與部署
純靜態 HTML/CSS/JavaScript，無需建置。GitHub Pages 使用 main 分支根目錄。

執行 `node tests.cjs`。臨床分流與計算測試涵蓋空白輸入、危急優先、缺漏血氣、呼吸／代謝性酸中毒、禁忌、FiO2 單位、P/F 與 ROX、監測能力。
